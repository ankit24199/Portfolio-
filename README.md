# Ankit Yadav — Portfolio

Personal portfolio website built with Next.js, React, and TypeScript.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm start
```

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Playfair Display + Inter (Google Fonts)

## Project Structure

```
app/          → Pages, layout, global styles
components/   → React components (layout, sections, ui)
hooks/        → Custom hooks
lib/          → Portfolio data
public/       → Images, resume, favicon
```
